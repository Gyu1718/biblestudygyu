# 사도행전 연구 서가 패키지 v3

대상 저장소: `Gyu1718/biblestudygyu`

## 반영 범위

- 기존 종합 개관과 1–5장 심층연구 유지
- 6장 HTML 심층연구 추가
- 7–10장 마크다운 원고를 기존 서가 형식의 HTML로 변환
- 1–10장 전체 장 이동 링크 활성화
- 11–28장은 준비 중 상태 유지
- 서가 홈의 책등, 연구 현황, 최신 추가분 바로가기 갱신
- 홈페이지 카탈로그를 `10편 완성`으로 갱신
- 창세기 서가 항목을 보존한 누적형 `catalog.js` 포함
- 루트 `index.html`의 카탈로그 캐시 버전을 `20260731.4`로 갱신

## 업로드 방법

압축을 푼 뒤 저장소 루트에 폴더 구조를 유지하여 업로드합니다.
기존 파일과 이름이 같은 파일은 덮어씁니다.

핵심 경로:

- `catalog.js`
- `index.html`
- `nt/acts/index.html`
- `nt/acts/overview.html`
- `nt/acts/ch01.html`–`ch10.html`

## 주요 기능 보완

- 모든 심층연구 페이지에서 1–10장 직접 이동
- 각 문서 하단에 이전 장·서가·다음 장 이동 메뉴
- 6–10장 검색 설명 메타데이터
- 7–10장 표, 주석 칩, 원어 표, 상호참조 표를 HTML 레이아웃으로 변환
- 서가 홈에 6–10장 최신 추가분 바로가기
- 10개 장의 활성 책등 및 연구 현황 카드

## 주의

`catalog.js`와 루트 `index.html`을 함께 덮어써야 홈페이지 카드와 캐시 갱신이 즉시 반영됩니다.
