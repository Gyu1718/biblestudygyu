# 사도행전 연구 서가 패키지 v2

대상 저장소: `Gyu1718/biblestudygyu`

## 반영 내용

- 사도행전 2장 심층연구: 오순절
- 사도행전 3장 심층연구: 미문의 표적
- 사도행전 4장 심층연구: 첫 심문
- 사도행전 5장 심층연구: 아나니아와 삽비라
- 사도행전 서가 홈에서 1–5장 책등과 연구 링크 활성화
- 1장 문서의 장 이동 메뉴에서 2–5장 링크 활성화
- 홈페이지 카탈로그를 `장별 심층연구 5편 완성`으로 갱신
- 아직 작성되지 않은 6–28장 책등을 공통 CSS 상태 클래스 `pending`으로 정리
- 2–5장 문서에 검색 설명 메타데이터 추가

## GitHub 웹 업로드 주의

GitHub의 `Add file → Upload files` 화면은 ZIP을 자동으로 풀지 않습니다. ZIP을 컴퓨터에서 먼저 푼 뒤, 폴더 구조를 유지하여 저장소 루트에 업로드해야 합니다.

업로드 후 다음 경로를 직접 확인합니다.

```text
https://gyu1718.github.io/biblestudygyu/nt/acts/
https://gyu1718.github.io/biblestudygyu/nt/acts/ch02.html
https://gyu1718.github.io/biblestudygyu/nt/acts/ch05.html
```

홈 카드가 바로 갱신되지 않으면 강력 새로고침(`Ctrl+F5`)을 실행합니다.
