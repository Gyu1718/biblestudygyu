# BOOK_STUDY_MANUAL 요엘 반영 패치

현재 저장소의 `docs/BOOK_STUDY_MANUAL.md`는 다른 작업과 충돌하지 않도록 이 패키지에서 통째로 덮어쓰지 않습니다. 아래 세 항목을 기존 문서에 반영합니다.

## 1. 문서 머리말의 표준형 적용 대상

기존:

```text
표준형 적용 대상: 느헤미야, 학개, 로마서 및 앞으로 추가되는 일반 성경책 연구 세트
```

변경:

```text
표준형 적용 대상: 느헤미야, 요엘, 학개, 로마서 및 앞으로 추가되는 일반 성경책 연구 세트
```

## 2. “표준형 현재 적용 대상” 목록

```text
- ot/nehemiah/
- ot/joel/
- ot/haggai/
- nt/romans/
```

## 3. “현재 적용 현황” 표에 행 추가

```markdown
| 요엘 | 표준형 | 활성 | v4 개정 | 1장 개정 완료, 2–3장 1차본 | 미구현 |
```

요엘의 장별 HTML은 한국어 3장 체계를 사용하고, 문서 본문에서 MT/BHS 4장 체계를 병기합니다.
