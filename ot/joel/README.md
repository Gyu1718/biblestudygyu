# 요엘 연구 세트

## 구현 상태

- `index.html`: 요엘 연구 서가 완성
- `overview.html`: 종합 연구 완성
- `ch01.html`–`ch03.html`: 한국어 3장 체계 장별 심층연구 완성
- `parsing/`: 미구현. 존재하지 않는 원어 연구 파일은 링크하지 않음

## 본문과 장 구분

- 공개 성경읽기 링크: `../../bible/original.html?book=JOL&chapter=N`
- 원문 리더: WLC/OSHB
- 연구 참고 본문: 사용자 제공 BHS
- 한국어 2:28–32 = MT/BHS 3:1–5
- 한국어 3:1–21 = MT/BHS 4:1–21
