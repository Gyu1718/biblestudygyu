# 요엘 연구 세트

## 현재 상태

- `index.html`: 요엘 연구 서가
- `overview.html`: 종합연구 v4 — 1장 구절별 개정의 논증과 독법 반영
- `ch01.html`: 구절별 주석 종합 개정 완료
- `ch02.html`: v3 1차본, 다음 개정 대상
- `ch03.html`: v3 1차본, 이후 개정 대상
- 원어 연구: 미구현

## 집필 규칙

각 해석 주장 앞에 해당 주석 칩을 둔다. 서로 다른 주석의 독법을 편집자의 단일 주장으로 합치지 않고 별도 문단으로 구분한다. 원본 PDF·EPUB·RTF는 배포하지 않는다.
