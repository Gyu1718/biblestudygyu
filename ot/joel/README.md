# 요엘 연구 세트 v3

## 집필·인용 원칙

- 저장소의 느헤미야·학개 연구 페이지와 같은 좌측 목차, 본문 폭, 장 이동 구조를 사용한다.
- 각 해석 주장 앞에 해당 주석의 인용 칩을 둔다.
- 한 문단에서 근거 주석이 바뀌면 문장 앞에 새 칩을 다시 둔다.
- 주석가 이름을 장식적으로 나열하지 않으며, 편집자의 독립 주장을 주석의 주장처럼 제시하지 않는다.
- 여러 주석이 같은 관찰을 공유하면 복수 칩을 문단 앞에 둔다.
- 상반된 견해는 각 견해의 문장 앞에 서로 다른 칩을 두어 구별한다.
