# 요엘 연구 세트 v2

## 집필 원칙

- 저장소의 느헤미야·학개 연구 페이지와 같은 좌측 목차, 본문 폭, 장 이동 구조를 사용한다.
- 주석가 칩의 수로 자료 사용을 표시하지 않는다.
- 본문 단락마다 주석의 실제 논증, 근거와 견해 차이를 서술형으로 통합한다.
- `overview.html`은 서론이 아니라 장별 개관·중심 신학·복음적 메시지·신학적 난제를 포함한 종합 연구 문서다.
- 장별 연구는 단락 구조, 절 범위 주해, 원어·문학 쟁점, 상호본문, 신학과 설교를 연결한다.

## 구현 상태

- `index.html`: 완성
- `overview.html`: 전면 재집필
- `ch01.html`–`ch03.html`: 전면 재집필
- `parsing/`: 미구현, 링크하지 않음

## 본문 정책

- 공개 원문 리더: WLC/OSHB
- 연구 대조: 사용자 제공 BHS
- 파일과 장 이동: 개역개정 3장 체계
- 문서 내부: MT/BHS 4장 체계 병기
