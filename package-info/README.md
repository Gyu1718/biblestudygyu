# 사도행전 1–15장 주석·신학 보완 원고

이 패키지는 기존 사도행전 장별 심층연구 HTML/Markdown에 **추가 삽입할 보완 원고**입니다.

## 작성 원칙

- 기존 절별 주해를 반복하지 않았습니다.
- Bruce NICNT, Peterson PNTC, Schnabel ZECNT의 해석 차이를 장별로 분리했습니다.
- 각 장의 신학적 연구 성과와 실제 난제를 별도 항목으로 정리했습니다.
- 전자책 페이지는 판본과 화면에 따라 달라지므로, 출처는 주석서와 본문 범위로 표시했습니다.
- 장별 파일 마지막의 “기존 원고에 삽입하기 좋은 보완 문단”은 바로 복사해 사용할 수 있는 압축 문단입니다.

1. `8. 주석가별 독법과 쟁점` 뒤
2. `11. 신학 종합` 앞
